## このアプリについて

間取りクイック3Dは、専門的なCADソフトを覚えなくても、部屋・壁・建具・家具を2Dキャンバスへ配置し、同じ内容を3Dで確認できるWebアプリです。

アカウント登録、インストール、バックエンドサーバーは不要です。作業中のデータはブラウザ内へ自動保存され、必要に応じてJSONファイルとして書き出せます。

### こんな用途に

- 小説、漫画、ゲーム、TRPGなどの舞台設計
- 引っ越し前の家具配置の検討
- リフォームや模様替えのラフ案
- 住宅・店舗・会場の簡易レイアウト
- 2Dと3Dを行き来しながらのアイデア整理
- WebGL、Three.js、Canvasを使った学習・試作

## すぐに使う

1. **[本番サイトを開きます](https://madori-5yu.pages.dev/)**。
2. 左側の「部屋」「壁」「ドア」「窓」「家具」などを選びます。
3. 2D画面をクリックまたはドラッグして配置します。
4. 「選択」で要素を選び、移動、サイズ変更、回転、色変更を行います。
5. 上部の「同時」「2D」「3D」で表示を切り替えます。
6. 大切なプランは「書き出し」からJSONファイルとして保存します。

インストールもログインも不要です。最初から用意されている間取りを編集するか、「テンプレート」から家・マンション・洋館・旅館・お店・病院・学校・寺・城・駅・遊園地・宇宙船など153種類の間取りを読み込めます。

## 主な機能

### 2D間取り編集

- 部屋をドラッグして作成。作った部屋・床には最初は名前を付けず、2Dに文字を出しません（必要なときだけ「選択中」で名前を付けられます）
- 「線で囲んで床を作成」で点を順につなぎ、好きな輪郭の床を2D・3Dに作成。凹形、作図中の戻す・やり直す、タップ操作にも対応
- 壁を直線・斜線で作成。壁の種類は、ふつうの壁・コンクリート・レンガ・ブロック塀・板塀・土塀（瓦の笠つき）・ガラス・石垣・生け垣・竹垣・フェンスから選べます（一覧の「壁」から選んで2Dをドラッグ。選んだ壁の種類も、選択中の欄の絵から変えられます）。厚み・高さ・色は種類ごとで、2Dは3Dを真上から見た形と同じです。石垣・生け垣・竹垣・フェンスは、自由な形と同じ見た目です。厚みは、選んだ壁の欄の「厚み」で変えられます（フェンス・竹垣を除く。厚くした壁も角がすき間なくつながります）
- ドア（開き戸）、両開きドア、引き戸、和風の建具（障子・襖・格子戸の玄関戸・板戸）、門扉（門戸）、戸のない開口（壁の切れ目）、通常窓、中央区切り付き窓を配置。ドアの種類は、置いたあとでも「選択中」の「扉の種類」で変えられます。開口は2Dでは壁の切れ目だけ、3Dでは戸のない出入口です。壁をクリックするだけでも、いつもの幅（ドア80cm・両開き160cm・窓120cmなど）で壁の上に置けます（開き戸は押した側に開きます。ドア・窓の上を押すと、そのドア・窓を選びます）。開き戸は「吊元（ちょうつがい）を反対側に」で、ちょうつがいの位置を変えられます。ドア・窓のツールでは、選択中の欄で置く幅を決められます（選んだドア・窓の「幅」を変えると、次からその幅で置きます）
- 扉の種類の「壁の大穴」（壁を突き破ったような、ふちのぎざぎざな大きな穴。まわりにひび）と「崩れ落ちた壁」（上が崩れて低くなった壁）は、壁をぎざぎざに切り抜き、足もとにかけらを散らします。3Dでは向こうが見え、2Dでは残った壁・崩れたふちと、3Dと同じ所のかけらを描きます。どの種類の壁でも、その壁の見た目のまま崩れます（石垣・生け垣・竹垣・フェンスは、大穴なら穴の上と下に垣が残り、崩れ落ちた壁なら崩れた所が段々に低くなり、ガラスは透けるガラスのかけら。低い壁は高さの半分ほどまで崩れます）。一覧の「壁」と「建物の部分・工事」にもあります
- 円、円弧、多角形を壁として3D化
- 家具・設備を配置し、移動、サイズ変更、回転、左右反転。幅・奥行は1cm単位で決められます（小物も小さいまま。角のハンドルでも、小さな家具は細かく変わります）。壁の近くに置くと、背を壁に向けて壁に付きます（`Alt`を押しながら置くと付けません。人・小物・床に描く物などは付けません）
- 部屋を動かすと、中の家具・文字・その部屋の壁とドア・窓・載っている屋根も一緒に動きます（隣の部屋との境の壁は動かしません。`Alt`を押しながらなら部屋だけ）。中に物がある部屋を消すと、一緒に消すかを聞きます（「キャンセル」で部屋だけ）
- 「削除」ツールは、クリックした物を消すほか、ドラッグすると通った所の家具・文字・ドア・窓を続けて消せます（部屋・壁は消しません。「元に戻す」1回で全部戻ります）
- 家具のデザインを「選択中」の見本から選択（椅子・ソファ・ベッド・テーブル・冷蔵庫・洗濯機・トイレ・植物・ラグ・岩・外灯・花壇・フェンス・スツール・番号の印・足跡・倒れた人・血など43種類。観葉植物の「らせんの葉」は、ひとつ前の標準の3Dの形を残したもの）。2Dの記号と3Dの形が同じデザインに変わります（例: 丸い座面の椅子は3Dでも丸い座面と曲げ木の背もたれ、布団を折り返したベッドは3Dでも掛け布団の角が折れ、ガラス天板のテーブルは3Dでもガラス越しに下の棚が見える）。`V`キーで順に切り替え、同じ種類を続けて置くと最後に選んだデザインを使います。「2Dの記号のみ」と書かれたデザイン（クローゼットの斜線など）は、3Dは標準の形のままです
- 3Dを真上から見た形は、2Dの記号と同じになるように作っています。岩の輪郭と稜線、池の輪郭と石の位置、飛び石・花壇の花の並び、木目、ラグの柄、植物の葉の向きなどは、2Dと3Dが同じデータから作られます（冷蔵庫の雪の結晶や靴箱の靴のように、見分けるための図柄は2Dだけに描きます）
- 部屋名を本文とは別にドラッグして自由配置
- 部屋名の「文字サイズ cm」を変更できます（空欄で自動）。部屋名と自由テキストは「横書き」「縦書き」を切り替えられ、縦書きの改行は右から左へ列を増やします。保存・Undo/Redo・PNGにも反映されます
- 「ペン」ツールで、好きな色で床に描けます（血だまりや汚れ、印などに）。2Dの上をドラッグすると線、クリックで点、「囲んで塗る」にすると囲んだ所を塗りつぶします。よく使う色（血の色・赤・黒・白など）から選ぶか、カラーコード（透明度も可）で決め、太さは1〜300cm。描いた線は3Dでも床に同じ形で描かれ、選ぶと色・太さ・描き方をあとから変えられます（線の上をクリックすると選べます）。描く前から、マウスの所にペン先の大きさの丸が出るので、太さが分かります（太さを変えている間は、2Dの真ん中に同じ丸が出ます）。ペンの欄の「描く物」で、川・小道・生け垣・石垣・フェンス・竹垣・線路・飛び石・池・花壇・芝生・ラグも選べます。川・小道などの線の形はなぞった道すじで描け（川・小道・生け垣・石垣は幅も決められます）、池・花壇・芝生・ラグは、はじめから「ペンで塗る」で、塗った所がその形になります（下の「自由な形」）。「描き方」で「直線で描く」「曲線で描く」にすると、なぞる代わりにクリックで点を打って描けます（直線は点と点をまっすぐ、曲線は点を通るなめらかな線でつなぎます。閉じる形は最初の点を押すと、線は Enter かダブルクリックで描き終えます。直線は、点を打つ前にドラッグすると1本の直線になります）。ペンの色や太さ、描く物、描き方はブラウザに記憶されます
- 「テキスト」ツールで間取りの好きな場所に文字を配置。内容（改行可）・大きさ・回転・色・太字を編集でき、ドラッグ移動・固定・Undo / Redo・保存に対応。空にすると削除。2Dだけに表示され、3Dには出ません
- 幅・奥行・長さ・角度・座標を数値で編集
- 2D色と3D色を個別指定。見本から選ぶほか、カラーコード（`#RRGGBB`）を直接入力できます。末尾に2桁足した`#RRGGBBAA`では透明度も決められ（`00`で透明〜`ff`で不透明。例: `#2775d180`で半分透ける）、2Dでは同じ色の要素をまとめて1回で透かすので重なった所や壁の角も同じ濃さ、3Dでは床・壁・建具・家具がまるごと透けます（透けている物は影を落としません）。見本では透明度が市松模様で分かり、見本で色を選び直しても透明度はそのまま。カラーコードを空にすると標準の色に戻ります
- 寸法ラベル（部屋・屋根の幅×奥行）の表示・非表示。初期状態は非表示
- 2Dの上の「表示」で、間取りの名前（書き出すファイルの名前になります）・部屋名の表示・部屋の広さ（帖・㎡。1帖は1.62㎡、階段の穴は引きます）・方眼の表示と大きさ（おまかせ・25cm・50cm・91cm（半間）・1m・1.5m・182cm（1間）・2m・3m）を切り替え。方眼の大きさを決めると、部屋の上にも方眼をはっきり重ねます。`G`キーで方眼の表示を切り替えられます
- 好きな画像（PNG・JPEG・WebP・GIF）を取り込めます。「画像を取り込む」を押すか、2Dに画像のファイルをドラッグすると、長い辺3mで置きます。2Dに描き、3Dでは床に貼ります（2Dと同じ向き・大きさ）。大きさ（縦横の比を保てる）・回転・反転・濃さを変えられ、濃さを下げて「配置を固定」すれば下絵にもできます。画像は長い辺1600pxまでに縮めて、間取りのデータ（自動保存・書き出しのファイル）に入ります
- 家具・画像を「最前面へ」「最背面へ」動かして、重なりの順を変えられます
- ほかの階を半透明で重ねる「透過」表示。横の▼から、透かす階（すぐ下・すぐ上・ほかの階すべて・階を名前で指定）、透かす色（カラーコード。空欄なら元の色）、濃さを選べます。透かした階は一度ふつうに描いてから1回だけ半透明で重ねるので、壁の角や重なった所も同じ濃さです
- 2D上の屋根の一時表示・非表示
- 2Dの「絵柄」で、間取り全体の描き方を切り替え（標準・モノクロ・設計図・CAD・コピー・鉛筆・水彩・クレヨン・黒板・筆と和風・墨絵・古地図・マンガ・ポップ・ドット・レトロゲーム・ネオン・ホラーの18種類）。詳しくは下の「2Dの絵柄」
- パーツ検索（ひらがな・カタカナ・別名でも検索可。例: いす、まど、れいぞうこ）
- 選択した要素の配置固定
- マウスホイールによるズーム（0.0001倍〜1万倍まで、ほぼ無限に拡大・縮小。遠くまで引くと方眼の間隔も自動で広がり、大きく拡大したときは部屋の中にも方眼を薄く表示して、右ドラッグで動かしていることが分かるようにします）
- 右ドラッグによるキャンバス移動
- 全体表示への自動フィット
- Undo / Redo

壁とドア・窓が重なった場所では、ドアと窓の開口が優先されます。2D図面と3Dモデルの両方で、壁が建具部分をふさがないよう処理されます。

### 3Dプレビュー

- 2D間取りをThree.jsでリアルタイム変換（2Dで家具・壁・床などをドラッグしている間も、3Dがすぐ追いつきます）
- `同時`、`2Dのみ`、`3Dのみ`の表示モード
- `同時`表示では、2Dと3Dの境目をドラッグして広さを自由に変更（境目を選んで矢印キーでも5%ずつ動かせます。ダブルクリックで元の半分ずつに戻ります）。境目の位置はブラウザに記憶され、タブレットやスマホの上下表示でも使えます
- マウスドラッグによる視点回転・移動。左ドラッグは押した所（マウスの下の物）を中心に回り、押した物が画面の同じ所にとどまります。上下の向きに制限はなく、真上から見下ろすことも、下から見上げることもできます
- ホイールによるズーム（マウスのある場所に向かって進み、拡大し続けると窓や壁を越えて室内まで入れます。近づいても前進が止まらず、逆回転で後退できます。タッチ操作ではピンチに対応）
- 右ドラッグの移動は、つかんだ物がマウスについてくる速さで動きます。すぐ目の前まで寄ったあとでも、止まったようにならず動かせます
- 壁、床、ドア、引き戸、障子・襖などの和風の建具、窓、家具、設備、階段、屋根を立体化
- 階段は出発する下の階に1つ配置すれば、到着する上の階の2D図とPNGにも下り向きの記号で自動表示します（下階の透過表示がオフでも表示）。上の階に同じ階段を複製する必要はありません。記号の位置・大きさは下階の階段に追従し、編集は下階で行います
- すでに上下階へ同じ階段を重ねていた場合は、上階の階段を選択して「下階の階段表示に切り替え」を押すと、上階の実物だけを削除して下階の記号表示にできます。固定中は操作できず、取り消しにも対応します。上階からさらに上へ登る階段は、そのまま残せます
- 草地・芝生の床には、細い草の葉が立ち上がって見えるように生やします（池・飛び石・ラグの下には生やしません）
- 3Dの絵柄を16種類から選べます（標準・リアル・白模型・線画・モノクロ・古写真・鉛筆・水彩・墨絵・アニメ・マンガ・ドット・レトロゲーム・設計図・ネオン・ホラー）。選んだ絵柄は記憶され、3Dの画像の書き出しにも使われます
- リアルの絵柄は、光（トーンマッピング・周りの映り込み・細かい影・物の間の暗がり）と、家具・設備の材質（木目・布目・金属の筋・石の粒・陶器や漆のつや など）を本物らしくし、空と地面も描きます
- 影のON/OFF
- 5段階の明るさ調整
- 8方位と真上から選べる光の向き
- 階ごとの表示・非表示
- 屋根全体の一時表示・非表示（屋根ごとに色も変えられ、透かせば中が見えます）
- 3D上の家具・ドア・窓はダブルクリックで選択（スマホ・タブレットは長押し）。マウスを乗せると薄い枠と「ダブルクリックで選択」の案内が出ます。1回クリックでは選択を変えず、選び方を案内します。固定した家具も選択でき、Ctrl／Cmd＋クリックでの複数選択はそのまま使えます。床・壁・屋根などは1回クリックで選択します
- 家具を選んで3D画面をクリックすると、編集中の階へ連続配置
- 「選択」ツールで家具をダブルクリックすると、その家具や複数選択した家具をドラッグで移動できます。3D欄の移動ボタン（十字の矢印）を押すと移動モードになり、何も選んでいなくても、押した物（床・壁・ドア・窓・屋根・家具など）をそのままドラッグで動かせます。移動モードは、もう一度押すか Esc で終わります。移動中のEscは元の位置に戻します。通常の左ドラッグは家具の上でも視点回転です
- 右ドラッグ／Shift＋左ドラッグは、画面に沿った上下左右の平行移動です。上下ドラッグで高さも変わり、2階・3階の室内まで視点を持ち上げられます

### 複数階

- 「＋」で上の階を、「＋B」で地下の階を、何階でも追加（地下はいちばん下に増え、B1F、B2F…と呼びます）
- 階はタブで切り替え（増えて入りきらないときは横にスクロール。`[` `]`キーでも下の階・上の階へ）。階を消すと残りの階の名前を付け直します
- 階のタブをダブルクリックすると、階に名前を付けられます（例: 地下牢・屋上）。タブ・3Dの表示の切り替え・書き出す画像の見出しとファイルの名前に出ます。空にすると、いつもの名前（1F・B1F など）に戻ります
- タブの右の重ねた四角のボタンで、いまの階を複製（すぐ上に同じ階が増え、この階の屋根は上の階へ移ります）
- ほかの階をゴースト表示（透かす階・色・濃さを選択可）
- 3Dでは階ごとに表示・非表示を切り替え
- 階高、床スラブ、最上階の壁上端を考慮して積層。地下の階は地面より下に積み、1Fの床が地下の天井をふさぎます

### ナイトモード

上のバーの月のボタンで、画面のまわり（ボタン・欄・メニュー）と3Dの背景を暗くできます。もう一度押すと元に戻り、選んだ明るさはブラウザが覚えます。2Dの間取りの紙は白のままです（書き出す画像と同じ見え方。暗い紙にしたいときは2Dの「絵柄」の背景で選べます）。

### 言語（日本語・英語・韓国語・繁体字中国語）

上のバーの「言語」（JP・EN・KR・繁中）で、画面の言語を切り替えられます。

- ボタン・メニュー・選択中の欄・お知らせ・確かめの窓・家具やテンプレートの名前と説明など、画面の文字がその言語になります。選んだ言語はブラウザが覚えます
- URL に `?lang=en`・`?lang=ko`・`?lang=zh-Hant` を付けても、その言語で開けます（覚えている言語より優先。覚えはしません）
- テンプレートの部屋の名前は、選んでいる言語で作ります。自分で書いた部屋の名前・文字は、言語を変えてもそのままです（間取りのデータは変わりません）
- 家具やテンプレートは、その言語の名前でも検索できます
- 何も選んでいなければ日本語です（ブラウザの言語からは決めません）。日本語以外では、広い画面の上のバーのお知らせ・注意書きは出しません（スマートフォンではお知らせを出します。注意書きは「このアプリについて」で読めます）
- 更新履歴は、日本語以外では英語の文を出します

### 間取り専用版（3Dなし）

3Dを使わずに2Dの間取りだけを編集したいときは、間取り専用版（https://madori-5yu.pages.dev/plan/ ）を使えます。

- 2Dの画面だけで、3Dの欄・表示の切り替え・3Dの色・高さ・屋根・3Dの画像の書き出しは出しません
- 間取りのデータは本体と共通です。間取り専用版で描いた間取りを、上部の「3Dでも見る」から本体で開いて3Dで確かめられます（同じブラウザのとき）
- 本体の表示の切り替えや3Dで見ていた向きは、間取り専用版を開いても変わりません
- 上のバーの文字の所に、新しいお知らせ、間取り専用版のお知らせ（本体だけ）、開発中の注意書きの順に1つずつ出します（横幅1600px以上の画面のとき。スマートフォンでは、上のバーのボタンの下に1行で出します）。×で消すと次の文に替わり、消した文は次からも出ません（新しいお知らせは、次のお知らせが出るとまた出ます）。広い画面では画面の高さは使いません

### 2Dの絵柄

2Dの上の「絵柄」から、間取り全体の描き方を選べます。メニューは「線画」と「背景」のタブに分かれていて、線の描き方と地（紙や板）を別々に選んで組み合わせられます（例: 鉛筆の線画を黒板に、ネオンの線画を羊皮紙に）。線画の見本はいまの背景で、背景の見本はいまの線画で描いて並べます。間取りのデータ（形・大きさ・色）と3Dは変わらず、描き方だけが変わります。選んだ線画と背景はブラウザに保存され、画像の書き出しもその絵柄になります。

- 線画は18種類で、線画・手描き・和と古風・マンガとゲーム・夜と雰囲気の5つに分けて並べます（下の一覧）
- 背景は14種類: おまかせ（線画に合わせる）・白・和紙・画用紙・水彩紙・羊皮紙・コピー用紙・クリーム・青焼き・黒板・黒・夜・暗がり・ゲームの緑。紙の模様や縁の暗がりも背景といっしょに変わります。筆の仲間の線画では、床の模様に重ねる色も背景の色になります

- 標準: これまでどおりの、くっきりした線画
- モノクロ: 標準と同じ線画を、色だけ白黒の濃淡にします（紙の模様やむらは付けません）。床の模様も色を抜いて残します
- ドット: ドット絵のマップのように、間取り全体を四角いドットで描きます。細い線はドットのます目に沿った1ドットの線（曲線は階段状、四角の角はそのまま）、壁などの太い線と塗りはドットごとに1色にまとめます。文字はぼかさずにくっきり描きます。ドットの大きさは細かい（2px）・ふつう（3px）・粗い（5px）から選べ、スクロールしてもドットの形がちらつかないよう、間取りを1ドットずつ動かします
- レトロゲーム: ドットの絵柄を、昔の携帯ゲーム機のような緑の4色だけで描きます。間の明るさは、決まった並びの点（ディザ）で隣の色と混ぜます。点の並びは間取りに貼り付いているので、スクロールしてもちらつきません。ドットの大きさも選べます
- 筆・和風: 和紙の地に、墨の筆で描いたように描きます。線は入りで押さえてふくらみ、止めで押さえて終わるか、払いで細く抜け、途中でも筆圧で太さが変わり、手で引いたように揺れて少し反ります。四角は辺ごとに筆を運び、角で少し突き抜けます。壁などの太い線（少し細い線も）は筆の毛ごとに描き、終わりの方でかすれます。1本の中でも、入りの方は墨が濃く、かすれる終わりの方は薄くなり、線のまわりは和紙に少しにじみます。塗りは縁が少し波打って少し濃くたまる淡い色で、むらがあり、白は和紙の色になり、最後に和紙の繊維とむらを重ねます。文字は楷書・教科書体（なければ明朝）で、墨が少しにじんだように描きます。同じ形の線はいつ描いても同じ形なので、動かしたりスクロールしたりしても線がちらつきません
- 鉛筆: 白い画用紙に、鉛筆で下描きしたように描きます。線は2〜3回なぞったように少しずつずれ、端は少し行き過ぎたり手前で止まったりします。壁などの太い線は細い線を並べて塗り、部屋や家具の塗りは色鉛筆の薄い色に、濃い色ほど細かい斜線（とても濃い所は網目）を重ねます。文字は手書きらしい教科書体です
- マンガ: 白黒で描きます。線は黒く、塗りは色の濃さに合わせたスクリーントーン（網点）に、とても濃い色はベタ（黒）になります。トーンは間取りに貼り付いているので、スクロールしても網点は動きません
- 設計図: 青焼きの図面のように、青い地に白っぽい線で描きます。塗りは淡い白、文字は図面の文字らしいゴシックです
- 古地図: 羊皮紙の地に、セピアのペンで描きます。色は褪せて紙になじみ、紙のむらと縁の暗がりを重ねます。文字は明朝です
- 黒板: 緑の黒板に、チョークで描きます。線は粉っぽくところどころかすれ、塗りは板の上に淡く、文字は手書きらしい教科書体です
- ネオン: 夜のように暗い地に、光る線で描きます。線の色はあざやかに明るくなり、まわりがぼんやり光ります
- CAD: 黒い画面に細い線で描きます。黒い線は白に、色のある線は色相ごとにCADらしい原色（赤・黄・緑・水色・青・紫）になり、塗りは地の色で下の線を隠します
- コピー: コピー機で刷った資料のように、白黒の濃淡を少し強めて描き、トナーのむらと粒を重ねます。床の模様も色を抜いて残します
- 水彩: 細い線と、透ける絵の具で描きます。色は少しあざやかに、塗りの縁には絵の具が少し濃くたまり、塗りの中にはむらが出ます。水彩紙の目を重ねます
- クレヨン: 太くてところどころかすれる線と、紙の目が白く残る塗りで描きます。色はあざやかです
- 墨絵: 色を使わず、墨の濃淡だけで描きます。強い赤（血など）だけは朱にします。床の模様も色を抜いて墨の濃淡にします
- ポップ: 太い黒い線と、あざやかな色の網点で描きます。灰色は白地に黒い点、とても濃い色はベタ（黒）です
- ホラー: 暗がりに、骨のような白っぽい線で描きます。赤い物（血など）だけは暗い赤ではっきりと描き、文字は赤くにじみます。汚れやしみ、ひっかき傷と、まわりの濃い暗がりを重ねます
- 筆の仲間（筆・和風、墨絵、古地図、黒板、水彩、クレヨン）では、床の模様（木・畳・タイル・石・草など）の上に紙や板の色を薄く重ね、模様の色が浮かないようにします
- 選択中の枠のつまみ・作図中の線・屋根の破線などの操作用の印は、どの絵柄でもくっきり描きます

### 画像の書き出し

上部の「画像」から、間取りをPNG画像にできます。

- 書き出す階: 表示中の階 / 全部の階を1枚に（階の名前付きで並べる） / 階ごとに1枚ずつ。複数の階は同じ範囲・同じ倍率にそろえるので、重ねて見比べられます
- 方眼と部屋の名前は入れるかどうかを選べます。寸法と部屋の広さは2Dの表示に合わせます。選択の枠・屋根・ほかの階の透過・固定の印は入りません
- 「表示」で方眼の大きさを決めて方眼を入れると、画像の端を方眼の線に合わせ（画像の左上から方眼が並ぶ）、「1マスの大きさ」で方眼1つを50〜140pxにできます。ココフォリアなどのマップのマス目に合わせられます
- 「背景を透明にする」で、地の色や紙の模様を入れずに書き出せます（ドットの絵柄では背景も入ります）。「画像をコピー」で、画像をクリップボードにコピーできます
- 2Dの「絵柄」が標準以外なら、画像もその絵柄で描きます（ドットは画面と同じ大きさのドット。筆は和紙、設計図は青い地、黒板は緑の板のように、地の色や紙の模様も入ります）
- 線の太さや文字の大きさの割合は、2Dで間取り全体を表示したときと同じにします（大きな間取りでも、縮めて見たときに線が細く薄くならないように）。細かさは画面の2倍以上・1cmが1.5ピクセル以上で、大きすぎる間取りはどの端末でも作れる大きさまで下げます
- 「3Dの画像（いまの見え方）」は、3Dで見ている向きのまま画面の2倍の細かさで書き出します
- ファイル名は`madori-YYYY-MM-DD-1F.png`、`madori-YYYY-MM-DD-all.png`、`madori-YYYY-MM-DD-3d.png`のようになります

### 複数屋根

- 切妻、寄棟、陸屋根、円すい、ドーム、正多角形を何枚でも追加
- 屋根ごとに幅、奥行、位置を編集
- 円すい・ドームは直径で一括変更、幅・奥行を別々に変えると楕円形に
- 正多角形は3〜12辺、向き、外接円の直径で編集。角をドラッグしても正多角形を維持
- 円すい・ドーム・正多角形は屋根の高さを10〜2000cmで指定（空欄なら寸法から自動計算）
- 「設置階」を屋根ごとに指定。階を追加しても設置階は変わらず、対象階を隠すと屋根も非表示
- 「上げ下げ cm」で屋根ごとに置く高さをずらせます（設置階の壁の上から。下げるときはマイナス、±3000cmまで）。同じ階の屋根でも、下屋や重なった屋根を別の高さに置けます
- 2D上でドラッグ移動
- 四隅のハンドルでサイズ変更
- 幅と奥行を90度入れ替え
- 2Dまたは3Dから屋根を選択。2Dでは屋根の縁（破線）か棟などの屋根の中の線をクリックします。床も家具もない軒先を押しても選べます（選択ツールのとき）。庭や地面の床の上にある線でも選べ、同じ所に線が重なるときは、いま見ている階の屋根を選びます
- 屋根ごとに色を指定（いぶし瓦・黒・赤茶・朱・緑青・青などの見本か、カラーコード）。末尾2桁で透かすと、3Dで屋根越しに中が見えます。2Dの屋根の線と面も、その色でうすく描きます
- 2D上の屋根には名前を表示せず、寸法表示がONのときだけ大きさを表示
- 屋根ごとの固定、選択、削除
- 旧形式の1枚屋根データを自動移行

部屋を選択してから屋根を追加すると、その部屋を覆う大きさで配置されます。部屋を選択していない状態で2枚目以降を追加すると、重なって見失わないよう右隣へ配置されます。

円・楕円・多角形の壁を選択して丸い屋根や正多角形の屋根を追加すると、その図形を基準に配置します。正多角形の壁では辺の数と向きも引き継ぎます。「魔法使いの塔」と「城」の塔は円すい屋根になりました（保存済みの間取りは変更しません）。

パネル上部の検索欄に入力すると、該当するパーツだけに絞り込めます。

各家具は2D用の平面記号と3Dモデルを持ちます。椅子や枕のように向きがあるものは背もたれ側を塗り分け、壁の高い位置に付くエアコンは破線で描きます。幅・奥行を変更しても、できるだけ形状の特徴を保つように生成されます。

和風の家具・鳥居・学校やお店の設備・遊具など（`src/furniture-shapes.ts` の `PART_KINDS`）は、箱・円柱・輪・横倒しの円柱・楕円体・傾けた板といった部品の組み合わせで作ります。2Dの記号は同じ部品を低い順に真上から描くので、3Dを真上から見た形と同じになります。高さを変えると部品の高さも一緒に変わり、竹垣・檻・ジャングルジム・カーテンは幅に合わせて柱やひだの数が増えます。神棚・提灯・黒板・額縁の絵・防犯カメラ・天井のダクトなどは壁に掛けたり天井から吊るしたりする物なので、3Dでも床から浮いた高さに付きます。メモ・鍵・携帯電話・ノートPCなどの小物は、机やテーブルの上に重ねて置くと、3Dではその家具の上にのります。

- 家具・設備・小物の410種類あまりに、クッション、脚、取っ手、棚板、寝具、家電の操作部などを個別に表現しています。
- 和風の12種類は幅・奥行・高さをそれぞれ調整できます（高さ1cm〜30m）。2D記号と3Dモデルは同じ部品の位置・寸法を使っています。
- 木・針葉樹・ヤシの木・低木・岩・フェンス・外灯・キャットタワーは「選択中」の「高さ cm」で高さを変えられます（10cm〜30m）。いちばん高い所がその高さになるように3Dを作ります。
- 2D記号には文字を使いません。形・線・塗り分けだけで見分けられるように描いています（番号の印に書く番号だけは別です）。
- 「人」と「倒れた人」は、体の関節を自由に動かせる人の模型です。3Dはデッサン人形のような、一色で関節に玉のある落ち着いた形です。「選択中」の「姿勢」で立っている・うつぶせ・あおむけを切り替え、「ポーズの見本」（気をつけ・歩く・手を上げる・両手を広げる・指さす・座る・ひざをつく・しゃがむ・うつぶせ・手足を広げて・あおむけ）から始めて、「関節の角度」で胴（腰を前・横へ倒す、ねじる）、首（うなずく・かしげる・振り向く）、腕・脚ごとの開く・前後・ひじやひざの曲げ・曲げる向き・手首・足首を変えられます。2Dで選ぶと、手首・足首（白）、ひじ・ひざ（水色）、頭に丸いつまみが出ます。手首・足首をドラッグするとその所まで手足が届き（寝ているときは床の上で、立っているときは腕や脚の向きを変えて）、ひじ・ひざをドラッグすると腕・脚の付け根が回り、頭をドラッグすると腰から曲がります。「身長」で大きさを変えられ、立つと約170cm。座る・ひざをつく・しゃがむでは、いちばん低い所が床に着くように体が下がります。体は太さのある部品（両端の太さが違う丸い部品と関節の玉）の集まりで、3Dはその部品を立体に、2Dは同じ部品を真上から見た形（立った人は頭や肩の輪郭を重ねて）を描くので、どのポーズでも2Dと3Dが同じ形です。倒れた人は、手足を動かすまでは前からある形のままで、デザインの「標準」「手足を広げて」を選ぶといつでもその形に戻せます。「チョークの線」は今のポーズの輪郭になります
- 自由な形: 池・花壇・芝生・ラグは、パーツを選んで2Dをドラッグで囲むと、その形になります（クリックだけなら、いつもの形）。川・小道・生け垣・石垣・フェンス・竹垣・線路・飛び石は、なぞった道すじに沿って置けます（クリックだけなら、まっすぐ）。川・小道・生け垣・石垣は幅を変えられ、「選択中」で形をなぞり直したり、いつもの形に戻したりできます。選ぶときは、範囲の四角ではなく形の上をクリックします。3Dも同じ形で、草地の草は川や小道の上には生えません。なぞって形を決められる物は、一覧のボタンの右に波線の印があり、「なぞって形を決める」の欄にもまとめてあります。どれも「選択中」の「描き方」で「直線で描く」「曲線で描く」にすると、クリックで点を打って描けます（石垣・竹垣・フェンス・生け垣・線路は、はじめから直線。描き方は物ごとに覚えます）。池・花壇・芝生・ラグは、描き方を「ペンで塗る」「囲んで描く」「直線で囲む」「曲線で囲む」から選べます。「ペンで塗る」は、2Dをドラッグして塗った所がその形になり、同じ種類の物に重ねて塗るとつながり、輪のように塗ると真ん中があいた形（ドーナツ）になります。「けずる」にすると、塗った所を取りのぞけます（真ん中をけずると穴）。塗る幅は10〜2000cm で、物ごとに覚えます
- 足跡は、パーツの「足跡」を選んで2Dをドラッグすると、なぞった道すじに沿って、歩く向きにつま先を向けた足跡が左右交互に付きます（クリックだけなら、まっすぐな足跡）。「選択中」で歩幅を変えたり、「道すじを描き直す」でなぞり直したり、「まっすぐにする」で戻したりできます
- 「人・事件・調査」の印は、探索や事件現場の図に使えます。番号の印は置くたびに次の番号（どの階も含めていちばん大きい番号の次）になり、「選択中」の「番号」で4文字まで書き換えられます。3Dでも札の上の面に同じ番号が出ます。足跡（靴・素足）、倒れた人（うつぶせ・手足を広げて・チョークの線）、血（血だまり・飛び散った血・引きずった跡）、破片は、2Dの形と3Dを真上から見た形が同じです。足跡と血は「色 2D」が跡の色になります
- 「破片」（割れたガラスなど）は、パーツの「破片」を選んで2Dをドラッグすると、なぞった所に破片が散らばります（クリックだけなら、前からあるひとまとまりの形）。「選択中」で、まく幅・量（少なめ・ふつう・多め）を変えたり、「なぞり直す」「ひとまとまりにする」ができます。色を決めていなければ透けたガラス、「色 2D」「色 3D」を決めるとその色の破片（陶器や木の破片など）になります
- 観葉植物は茎と葉、水槽は透明なガラスと魚・水草、時計は目盛りと針を持ちます。テレビ画面は幅に合わせて16:9の比率を維持します。
- 色変更は主な張地・本体に適用され、ガラス、金属、文字盤、葉などの色は維持します。
- 開き戸は3Dでは閉じた状態です。引き戸は別々のレールに配置した2枚の扉、窓は枠・サッシ・ガラス・取っ手で表現します。
- 和風の建具は、障子が組子の格子と和紙と腰板、襖が黒い縁と引き手、格子戸（玄関戸）が細かい縦格子とすりガラスと腰板、板戸が縦板の継ぎ目と裏の横桟です。2.4m以上の広い障子・襖は、引き違いの4枚建て（外の2枚が奥、中の2枚が手前のレール）になります。2Dの記号は、3Dと同じ板の並び・組子や格子の位置を、真上から見た形で描きます（障子は白い戸に組子の線、襖は塗った戸と黒い縁、格子戸は細かい線、板戸は木の色）
- 両開きドアと門扉は、両端のつりもとから半分ずつの扉が同じ側へ開きます。門扉は縦の板を間をあけて並べた扉で、2Dでは板の継ぎ目を描きます
- 幅・奥行は3Dの設置範囲にも反映され、回転・反転後も保持されます。既存の保存JSONはそのまま利用できます。
- 不透明な部品は材質ごとにまとめて描画し、細部を増やした際の描画負荷を抑えています。実製品を再現したCADモデルではありません。

「床・地面」で素材（22種類）を選び、2Dキャンバスをドラッグすると、その床材の領域を配置できます。斜めにドラッグすると四角、ぐるっとなぞると、その形の床になります（部屋のツールも同じです）。「描き方」で「直線で囲む」「曲線で囲む」にすると、「線で囲んで床を作成」と同じく、クリックで点を打って床を描けます（曲線は点を通るなめらかな形）。「ペンで塗る」にすると、ドラッグして塗った所がその床材の床になります。同じ床材の床（名前の付いた部屋を除く）に重ねて塗るとつながり、輪のように塗ると真ん中があいた床（ドーナツ）になります。「けずる」にすると、塗った所の同じ床材の床を取りのぞけます（真ん中をけずると穴）。畳は180×90cmの畳を半畳ずつずらして敷いた模様、レンガ・石畳・モザイクタイル・市松などは実際の大きさの目地で描きます。既存の部屋は「選択中」の「床材」の模様の絵から選んで変更できます。幅・奥行、2Dと3Dの色を調整でき、素材は上階にも反映されます。模様は寸法に合わせて繰り返すため、広げても引き伸ばされません。床材も自動保存・JSON書き出し・Undo/Redoに対応し、従来のデータは標準床として読み込まれます。

ラグは家具の下に表示されます。床やラグを後から追加した場合も、上に見えている家具を選択できます。

「線で囲んで床を作成」を選び、2Dで角になる点を順にクリック（タップ）します。始点をもう一度押す・`Enter`・キャンバス上のチェックボタンで閉じると、その形の床ができます。`Shift`で最後の点から水平・垂直に、`Backspace`または戻るボタンで1点戻し、やり直しボタンで復元、`Esc`または×で中止できます。交差した輪郭は確定せず、理由を表示します。作図だけでは壁は作られません。

既存の床は長方形・円・楕円・正多角形・L字の見本で形を変更できます。通常の選択では全体のサイズを変更し、「なぞり直す」で2Dをぐるっとなぞるとその形（斜めにドラッグすると四角）に描き直せます（床材・名前・色はそのまま）。「輪郭を編集」では頂点をドラッグ、辺の中央の＋をクリック・ドラッグで点を追加します。選んだ頂点は青く表示され、座標欄、矢印キー（1cm、Shift付きで20cm）、`Delete`で調整・削除できます。完了ボタンまたは`Esc`で通常の選択に戻ります。階段の穴が床の外に出る変更は、穴を消さずに止めます。

正多角形の床は、床を選んで形の見本の六角形を押すと作れます。「辺の数」で三角形〜十二角形、「向き」で角度、「外接円の直径」で大きさを指定できます。頂点のつまみや幅・奥行を変更しても、辺の長さがそろうように縦横を一緒に拡大縮小します。「輪郭を編集」で頂点を個別に動かすと自由な形に変更できます。正多角形の床を選んで正多角形の屋根を追加すると、辺数・向き・中心がそろいます。床材・名前・色はそのまま引き継ぎ、階段の開口が床の外に出る形への変更は止めます。

円の壁・円形の床は、円周の4つのつまみ、直径の数値、＋／−、スライダーで中心を保って拡大縮小できます。円形床の幅・奥行を個別に変えると楕円になります。円弧・多角形の壁も外周のつまみと直径欄で変更できます。スライダー操作は1回のUndoで戻せます。図形の壁の「この図形に合わせて床を追加」は元の壁を残して円・円弧（扇形）・多角形に合う床を作ります。床の輪郭は2D・3D・PNG・JSONで共通です。

楕円の壁は「図形の壁」の「楕円」を選び、2Dで四角を描くようにドラッグして配置します。既存の円でも「幅 cm」「奥行 cm」を別々に変えるだけで楕円になります。楕円の壁・床は左右のつまみで幅、上下のつまみで奥行だけを変更でき、中心は動きません。楕円の壁に合わせた床も追加できます。壁の形を「円」に戻すと縦横が同じになり、`R`で楕円の縦横を入れ替えられます。

左上のパネル切替ボタンで、編集パネルを一時的に隠せます。作業内容に応じて、上部の表示切替から2Dまたは3Dを広く表示できます。

## 保存、書き出し、読み込み

### 自動保存

間取りはブラウザの`localStorage`へ自動保存されます。ログインやクラウド保存はありません。

一部の項目が壊れている場合は、元データを退避して読み込める項目を復旧します。画面上部の「元データを書き出し」から、元のJSONをそのまま取得できます。容量不足などで退避できない場合は、元データを上書きしないよう自動保存を停止します。その場合、編集中の内容は通常の「書き出し」で保存してください。構文が壊れたJSONは自動復旧できませんが、元データの取得は可能です。

「新規」は作成済みの要素がある場合に確認を表示します。確定した後もUndoで戻せます。名前などの入力中は、Ctrl / Cmd + Zは入力欄の文字だけを取り消します。

複数選択した物の1つをドラッグすると、間隔を保ってまとめて移動します。固定した物はその場に残ります。「選択中」で一括固定・削除・選択解除ができ、移動や削除は1回のUndoで戻せます。3Dでは選択した家具をつかんで動かします。右ドラッグ／Shift＋左ドラッグは視点移動です。

複数選択中のRキーは全体を中心のまわりに90度回転します。コピーはアプリ内だけで使うクリップボードです。同じ階への複製・貼り付けは40cmずらし、別の階への貼り付けは元の位置を保ちます。

部屋・壁などを描くツールでも、物を短くクリックすると選択に戻れます。家具・文字の配置や消去のツールでは、物をダブルクリックするか約0.45秒長押しすると、配置・消去せずに選択できます（ダブルクリックの1回目で置いた家具・消した物は取り消します）。3Dでも、家具を置くツールのままダブルクリックすると、そこにある物を選べます。スマホ・タブレットでは2回タップか長押しです。家具の配置とそのままのドラッグは1回のUndoで取り消せます。

- 保存キー: `madori-quick-3d-plan`
- 表示モード、2Dと3Dの境目の位置、寸法表示、影、光、透過表示（透かす階・色・濃さ）、2Dの絵柄とドットの大きさ、画像の書き出しの設定もブラウザへ保存
- 再読み込みしたり開き直したりしても、2Dで見ていた場所と倍率、3Dのカメラの位置と向き、3Dで隠した階・屋根、2Dの屋根の表示、ツールパネルの開閉、左の一覧の開閉、家具ごとに選んだデザインをそのまま戻します（表示モードを切り替えたとき、テンプレート・新規・読み込みのときは全体が入るように合わせ直します）
- 通常は再読み込みやブラウザ再起動後も復元
- サイトデータ、Cookie、ストレージを削除すると消去
- 別ブラウザ、別PC、別ドメインには自動同期されない

### JSON書き出し

上部の「書き出し」で、プラン全体を`madori-YYYY-MM-DD.json`として保存します。階、部屋、壁、建具、家具、図形、複数屋根、色、位置、固定状態、番号の印の番号（`markerLabel`）が含まれます。

### JSON読み込み

上部の「読み込み」で、以前に書き出したJSONを復元できます。旧バージョンの単一階データや1枚屋根データも、可能な範囲で現在の形式へ変換します。

### ファイルの組み合わせ

上部の「組み合わせ」で、書き出したJSONを、いまの間取りに足せます。ファイルはいくつでも一度に選べます。置き方は次の3つから選びます（選んだ置き方は覚えておきます）。

| 置き方 | 内容 |
| --- | --- |
| 右に並べる | いまの間取り（屋根も含む）の右へ200cmあけて、上の端をそろえて置きます。複数のファイルは順に右へ並びます |
| 同じ位置に重ねる | ファイルに保存された位置のまま足します |
| 上の階に積む | ファイルの階を、いまのいちばん上の階の上に足します |

並べる・重ねるときは、1Fは1Fへ、地下は地下へと同じ階どうしを合わせ、足りない階は足します。屋根は元の階と一緒に移り、足した物には新しいIDが付きます。足したあとは、表示中の階の足した物が選ばれた状態になるので、そのままドラッグや矢印キーで位置を直せます。1回の「元に戻す」で、足した物も足した階も元に戻ります。何もない間取りに足すときは、ファイルの位置と階のまま入れます。

> [!TIP]
> 重要なプランは、ブラウザの自動保存だけに頼らず、定期的にJSONを書き出してください。

## データとプライバシー

- 間取りデータは利用中のブラウザ内に保存
- 間取りデータをアプリのサーバーへ送信しない
- アカウント、データベース、クラウド同期なし
- 広告なし
- 訪問数の把握にはCloudflare Web Analyticsを使用
- Cloudflare Web AnalyticsはCookieを使用せず、個人を追跡しない構成
- ご意見・ご要望のフォームはGoogleフォーム。フォームに書いた内容と、自動で入る使用環境（アプリの版・ブラウザ・画面の大きさ・URL）はGoogleに送られる。間取りのデータは送られない。画像付きのフォームでは、送った人のGoogleアカウントの名前・メールアドレス・写真が記録される

JSONファイルを「読み込み」した場合も、処理はブラウザ内で行われます。

## データモデル

書き出しJSONの最上位は、おおむね次の構造です。

```json
{
  "floors": [
    {
      "id": "floor-...",
      "name": "1F",
      "entities": [
        {
          "id": "room-...",
          "type": "room",
          "name": "LDK",
          "x": 0,
          "y": 0,
          "w": 600,
          "h": 400,
          "color": "#ffffff"
        }
      ]
    }
  ],
  "activeFloor": 0,
  "selectedId": null,
  "roofs": [
    {
      "id": "roof-...",
      "type": "roof",
      "kind": "gable",
      "x": -40,
      "y": -40,
      "w": 680,
      "h": 480
    }
  ]
}
```

座標と寸法の単位はセンチメートルです。主な`entity.type`は`room`、`wall`、`door`、`window`、`furniture`、`shape`、`text`です。家具の`symbol`はデザイン番号（2Dの記号と3Dの形で共通。標準のときは省略）、`height`は高さを変えられる家具の高さ（標準のときは省略）です。色は`#rrggbb`、透明度があるときは`#rrggbbaa`で保存します（読み込み時は`#RGB`や大文字も受け付けます）。`floors`は下の階から順に並び、地下があるときは`basements`に地下の階の数が入ります（先頭から`basements`個が地下。地下がなければ省略）。屋根は全階共通の`roofs`配列で管理し、各屋根の`floorId`で設置階、`color`で屋根の色（標準の色のときは省略）、`elevation`で置く高さのずれ（cm。0のときは省略）を指定します。未指定の旧データは読み込み時の最上階に割り当てます。設置階を削除すると対応する屋根も削除され、Undoで一緒に戻せます。

## トラブルシューティング

### `npm`を実行できない

Windows PowerShellの実行ポリシーで`npm.ps1`が止められる場合があります。

```powershell
npm.cmd install
npm.cmd run dev
```

### `ERR_CONNECTION_REFUSED`が表示される

開発サーバーが起動していません。プロジェクトフォルダーで`npm.cmd run dev`を実行し、ターミナルを閉じずに`http://127.0.0.1:5173/`を開いてください。

### 3Dが真っ白、または表示されない

- ブラウザを最新版へ更新
- ChromeまたはEdgeでハードウェアアクセラレーションを有効化
- WebGLが無効化されていないか確認
- ブラウザ拡張機能を一時的に無効化
- ページを再読み込み

### 保存した間取りが消えた

サイトデータの削除、シークレットモードの終了、別ドメインへの移動で`localStorage`が変わると復元できません。書き出したJSONがある場合は「読み込み」から復元してください。

### Cloudflare版とGitHub Pages版でデータが違う

ブラウザストレージはドメインごとに分離されています。`madori-5yu.pages.dev`と`tghcgu.github.io`のデータは自動共有されません。JSON書き出し・読み込みで移動してください。

- 対象ブランチが`main`または`develop`か確認

## 現在の制限

- α版のため、データ形式やUIが予告なく変わる可能性があります。
- PC操作を前提にしていますが、スマートフォンでも使えます。幅760px以下では、画面の高さに収めて開いてすぐ間取りを見せ、道具・家具の一覧は左上の ≡ で開く引き出し（指で選ぶと閉じます）、書き出しなどは上のバーの「…」、選んだ物の設定は下から出る欄（見出しだけにたたんで出し、見出しを押すと開きます。≡ の引き出しを開いている間は、引き出しの「選択中」に出します）になります。指で1つ置くと「選択」に戻るので、続けてほかの物をタップで選べます。スマートフォン・タブレットの2Dでは、タップで選び、選んだ物はドラッグで動かす（つまみで大きさを変える）、ほかの所のドラッグで地図を動かし、2本指でつまむと拡大・縮小します。お知らせは、スマートフォンでは上のバーのボタンの下に1行で出します（開発中の注意書きは出しません）。
- 建築CAD、構造計算、法規確認、施工図作成の代替ではありません。
- 寸法、壁厚、建具、家具、屋根の表現は簡易モデルです。
- クラウド保存、ログイン、共同編集、URL共有はありません。
- ブラウザやGPUによって3Dの描画品質・速度が異なります。
- 非常に大きいプランや部材数の多いプランでは処理が重くなる場合があります。
- 自動保存データはドメインとブラウザプロファイルごとに分かれます。

## About

Madori Quick 3D is a browser-based floor plan editor for quickly placing rooms, walls, openings, furniture, and equipment on a 2D canvas and reviewing the same plan as an interactive 3D model.

It requires no account, installation, backend server, or database. Work is saved automatically in the browser and can be exported as a JSON file for backup or transfer.

### Good for

- Planning locations for novels, comics, games, and tabletop RPGs
- Trying furniture layouts before moving or redecorating
- Sketching renovation and room arrangement ideas
- Creating rough home, shop, office, or venue layouts
- Exploring ideas while switching between 2D and 3D
- Learning or prototyping with Canvas, WebGL, and Three.js

## Quick Start

1. **[Open the production app](https://madori-5yu.pages.dev/)**.
2. Choose a room, wall, door, window, shape, or furniture tool from the left panel.
3. Click or drag on the 2D canvas to place it.
4. Use the Select tool to move, resize, rotate, recolor, or lock an item.
5. Switch between Split, 2D, and 3D views from the top bar.
6. Export important plans as JSON using the Download button.

You can edit the starter plan immediately or load one of 153 templates, from houses and a condominium to a Western mansion, a ryokan, shops, a hospital, a school, a temple, a castle, a train station, an amusement park, and a spaceship.

## Feature Overview

### 2D editing

- Draw rooms by dragging. New rooms and ground areas start without a name, so no text appears in 2D until you add one under Selection
- Draw horizontal, vertical, and angled walls. Choose a wall type: plain, concrete, brick, block wall, board fence, earthen wall with a tile cap, glass, stone wall, hedge, bamboo fence or fence (pick one in the Walls group and drag on the 2D plan, or change a selected wall's type from pictures in the selection panel). Each type has its own thickness, height and color, and the 2D symbol matches the 3D view from above; stone walls, hedges, bamboo fences and fences look the same as the free shapes
- Add swing doors, double doors, sliding doors, Japanese fittings (shoji, fusuma, a lattice entrance door and a plank door), gates, plain openings (a gap in the wall), windows, and divided windows. The door type can be changed later under Selection. An opening is just a gap in the wall in 2D and a doorway without a door in 3D. A click on a wall also places one with the usual width (80 cm for a door, 160 cm for a double door, 120 cm for a window and so on); a swing door opens toward the side you clicked, and clicking an existing door or window selects it. A swing door's hinge can be moved to the other end under Selection. With a door or window tool active, the Selection panel sets the width to place (changing the width of a selected door or window also sets it for the next ones)
- The door types "large hole in the wall" (a big hole blown through the wall, with a ragged rim and cracks around it) and "collapsed wall" (a wall whose top has fallen in) cut the wall with jagged edges and scatter rubble on the floor. 3D shows the view through the gap; 2D draws what is left of the wall, the broken edge and the rubble in the same places as in 3D. Every wall type breaks in its own look (a large hole in a stone wall, hedge, bamboo fence or fence leaves the fence above and below it; a collapse steps down where it fell; glass breaks into see-through shards, and low walls collapse to about half their height). Both are also listed in the wall and building-parts groups
- Turn circles, arcs, and polygons into wall geometry
- Place, move, resize, rotate, and flip furniture. Width and depth can be set to the centimeter (small items keep their size, and corner handles resize small pieces in finer steps). Furniture placed near a wall turns its back to the wall and touches it (hold `Alt` to skip; people, small items and floor marks never snap)
- Moving a room moves its furniture, text, its own walls, doors and windows, and the roof on it as well (walls shared with the next room stay; hold `Alt` to move only the room). Deleting a room with things inside asks whether to delete them too (Cancel deletes only the room)
- The Delete tool removes what you click, and dragging it removes every piece of furniture, text, door or window it crosses (rooms and walls stay; one Undo brings them all back)
- Drag room labels independently from room geometry
- Choose a different design for furniture from the thumbnails under Selection (43 types, including chairs, sofas, beds, tables, fridges, washers, toilets, plants, rugs, rocks, garden lights, flower beds, fences, stools, numbered markers, footprints, the fallen person, and blood; the plant's "spiral leaves" design keeps the previous standard 3D shape). The 2D symbol and the 3D model change together (for example, the round-seat chair also has a round seat and a bentwood back in 3D, the bed with a folded-back duvet shows the folded corner in 3D, and the glass-top table shows its lower shelf through the glass). Press `V` to cycle through them. New items of the same type use the last design you picked. Designs marked "2D symbol only" (such as the hatched closet) keep the standard 3D model
- Seen from directly above, each 3D model matches its 2D symbol. Rock outlines and ridges, pond outlines and rim stones, stepping stone and flower layouts, wood grain, rug patterns, and plant leaf directions are generated from the same data for 2D and 3D (identifying marks such as the fridge snowflake or the shoes on the shoe cabinet appear only in 2D)
- Draw on the floor in any color with the Pen tool (for blood, stains or marks): drag for a line, click for a dot, or choose "囲んで塗る" to fill the area drawn around. Pick a common color (blood red, red, black, white, ...) or a color code (with transparency), and a width from 1 to 300 cm. Strokes appear with the same shape on the 3D floor; select one by clicking on its line to change its color, width or fill later. A circle the size of the pen tip follows the mouse before you draw, so you can see the width (while you change the width, the same circle appears in the middle of the plan). Under 描く物 (what to draw) in the pen settings you can also choose a river, path, hedge, stone wall, fence, bamboo fence, railway, stepping stones, pond, flower bed, lawn or rug. Line shapes such as rivers and paths follow the traced path (rivers, paths, hedges and stone walls have a width setting), while ponds, flower beds, lawns and rugs start with ペンで塗る (paint): the painted area takes that shape (see Free shapes below). Choose 直線で描く (straight lines) or 曲線で描く (curves) under 描き方 (drawing method) to click points instead of tracing: straight lines join the points directly, curves pass smoothly through them, closed shapes finish when you click the first point, and lines finish with Enter or a double-click. With straight lines, a drag before placing any point draws one straight line. The pen color, width, what it draws and the drawing method are remembered in the browser.
- Place free text anywhere on the plan with the Text tool. Edit content (multi-line), size, rotation, color, and bold; move, lock, undo/redo, and save it like other items. Clearing the text deletes it. Text appears only in 2D, not in 3D
- Room labels also have a font size field (blank restores automatic sizing). Both room labels and free text support horizontal and vertical writing, with new vertical columns flowing right to left. Selection bounds, dragging, undo, saved files and PNG use the same layout
- Choose "線で囲んで床を作成" to draw a floor by clicking or tapping successive corners. Close it by clicking the first point, pressing Enter or the check button. Shift constrains the next segment horizontally/vertically; Backspace or the undo button removes the last draft point, redo restores it, and Escape or the cancel button discards the draft. Crossed outlines are rejected with feedback. This creates a floor, not walls
- Existing floors have rectangle, circle, ellipse, regular polygon and L-shaped previews. Normal selection resizes the whole floor; "なぞり直す" (retrace) lets you trace around an area in 2D for a new shape (or drag diagonally for a rectangle), keeping its material, name and colors; "輪郭を編集" enables direct vertex editing. Click or drag an edge midpoint to insert a point, adjust the selected point through coordinates or arrow keys (1 cm, or 20 cm with Shift), and press Delete to remove it. The active point stays highlighted across edits. Finish or press Escape to return to normal selection. Changes that would invalidate stairwell holes are blocked without deleting the holes
- To make a regular polygon floor, select a floor and press the hexagonal preset. Choose 3 to 12 sides, rotation and circumcircle diameter. Perimeter handles and width/depth inputs resize proportionally to keep all sides equal. Contour editing can turn it into a freeform floor. Adding a polygon roof while the floor is selected matches its sides, orientation and center. Materials, names and colors are retained; shape changes that would expose stairwell holes are blocked
- Circle walls and circular floors have four perimeter handles, an exact diameter field, increment/decrement buttons and a live slider. Resizing keeps the center fixed; a slider gesture is one undo step. Changing a circular floor's width and depth independently makes an ellipse. Arc and polygon walls also have radial size handles and a diameter control. Shape walls can add matching floors while keeping the wall; arcs produce sector floors. 2D, 3D, PNG and JSON share the same outline, including concave cutouts and overlap clipping
- Draw an ellipse wall by choosing "楕円" under Shape walls and dragging a bounding rectangle. Alternatively, edit an existing circle's width and depth independently. Ellipse wall and floor handles change only their own axis while keeping the center fixed. Add a matching ellipse floor from the wall properties, switch the wall shape back to Circle to restore equal axes, or press R to swap the ellipse's axes
- Edit dimensions, line length, angle, coordinates, and colors numerically
- Set separate 2D and 3D colors. Pick a swatch or type a color code (`#RRGGBB`); two more digits (`#RRGGBBAA`) set transparency (`00` clear to `ff` solid, e.g. `#2775d180` is half see-through). In 2D, items of the same color are made see-through together so overlaps and wall corners stay even; in 3D, floors, walls, openings and furniture become see-through as a whole (and cast no shadows). Clearing the code goes back to the default color
- Toggle dimension labels for rooms and roofs (off by default)
- The 表示 (view) menu above the 2D plan names the plan (the name is used for exported files), toggles room names, shows room areas in tatami mats (帖, 1.62 m² each, stairwell holes excluded) or square meters, and turns the grid on or off with a size of auto, 25 cm, 50 cm, 91 cm (half a ken), 1 m, 1.5 m, 182 cm (one ken), 2 m or 3 m. A chosen size is drawn clearly over rooms too; `G` toggles the grid
- Import any image (PNG, JPEG, WebP or GIF) with 画像を取り込む or by dragging the file onto the 2D plan; it is placed 3 m on its longer side, drawn in 2D and laid on the floor in 3D at the same size and angle. Size (optionally keeping the aspect ratio), rotation, flip and opacity can be changed; a faint, locked image works as a tracing underlay. Images are scaled to at most 1600 px and stored in the plan (autosave and exported files)
- Bring furniture and images to the front or send them to the back
- Show other floors as a translucent guide ("透過"). The ▼ next to it picks which floors (the one below, the one above, all others, or one by name), a tint color (a color code, or blank for the original colors) and the strength. Ghost floors are drawn normally first and made see-through once, so wall corners and overlaps stay even
- Temporarily hide roofs on the 2D plan
- Switch how the whole 2D plan is drawn with "絵柄" (18 styles: standard, monochrome, blueprint, CAD, photocopy, pencil, watercolor, crayon, chalkboard, brush on washi, ink wash, old map, manga, pop, dots, retro game, neon, and horror); see "2D styles" below
- Search parts by name, including hiragana, katakana, and common aliases
- Lock selected items to prevent accidental movement or deletion
- Zoom with the mouse wheel (almost without limit, from 0.0001x to 10,000x; the grid spacing widens automatically when zoomed far out, and when zoomed far in the grid also shows faintly inside rooms so you can see the view moving) and pan with right-drag
- Fit the complete plan to the viewport
- Undo and redo editing operations

When a wall overlaps a door or window, the opening takes priority. The wall is split around the opening in both the 2D drawing and generated 3D model.

### 3D preview

- Real-time conversion from the 2D plan using Three.js (the 3D view follows while you drag furniture, walls or floors in 2D)
- Split, 2D-only, and 3D-only view modes
- In Split view, drag the boundary between 2D and 3D to resize them freely (or focus it and use the arrow keys to move it 5% at a time; double-click to go back to half and half). The browser remembers the position, and it also works in the stacked layout on tablets and phones
- Orbit, pan, and zoom camera controls. Left-drag orbits around the point you press (whatever is under the mouse stays put), with no limit on the vertical angle, so you can look straight down or up from below. The 3D view zooms toward the mouse pointer; keep scrolling to pass through windows and walls into rooms, and reverse to move back. Forward movement no longer stops near the orbit target. Pinch gestures work too. Right-drag moves the view so that whatever you grab follows the pointer, and it keeps moving at a usable speed even when zoomed right up to a surface
- 3D walls, floors, doors, sliding doors, Japanese fittings such as shoji and fusuma, windows, furniture, equipment, stairs, and roofs
- Place a staircase once on its departure floor. Its arrival is shown automatically as a descending symbol in the next floor's 2D plan and PNG export, even with floor ghosting off. No extra 3D flight is created. The symbol follows edits to the original staircase; edit it on the lower floor
- For an existing duplicate, select the upper flight and choose "下階の階段表示に切り替え" (use the lower-floor stair display). This removes only that upper flight, supports undo, and is disabled for locked stairs. Keep an upper flight when it intentionally leads to another floor
- Grass floors grow thin blades of grass in 3D (except under ponds, stepping stones, and rugs)
- 16 looks for the 3D view: standard, realistic, white model, line art, monochrome, old photo, pencil, watercolor, ink wash, anime, manga, pixel art, retro game, blueprint, neon and horror. The chosen look is remembered and used for 3D image export
- The realistic look adds tone mapping, environment reflections, finer shadows and ambient occlusion, draws a sky and ground, and gives all furniture and equipment realistic materials (wood grain, fabric weave, brushed metal, stone grain, glossy ceramics and lacquer, and more)
- Optional shadows
- Five light intensity levels
- Eight compass directions plus overhead lighting
- Per-floor visibility controls
- Temporary roof visibility toggle
- Double-click furniture, doors and windows in 3D to select and edit them (long press on phones and tablets); hovering shows a light outline and a "Double-click to select" tip, and a single click does not change the selection and explains how to select instead. Locked furniture can still be selected, and Ctrl/Cmd-click still adds or removes items from a group. Floors, walls, roofs and other objects use a single click
- In Select mode, double-click furniture, then drag it (or its selected group). The move button (cross arrows) in the 3D bar turns on the move mode: even with nothing selected, drag whatever you press, including floors, walls, doors, windows, roofs and furniture. Press it again or Escape to finish; Escape during a drag restores the starting position. Normal left-drag rotates the view, including over furniture. Right-drag or Shift-left-drag moves in the screen plane, including up/down elevation for exploring upper floors

### Multiple floors

- Add floors above with "＋" and basements with "＋B"; switch floors with the tabs or the `[` and `]` keys
- Double-click a floor tab to name the floor (for example, a dungeon or a rooftop). The name shows on the tabs, the 3D floor toggles, and exported image headings and file names; leave it empty to go back to the usual name (1F, B1F and so on)
- The overlapping-squares button next to the tabs duplicates the current floor directly above it (this floor's roofs move up onto the copy)
- Translucent lower-floor reference in 2D
- Per-floor visibility in 3D
- Stacked floor heights, slabs, and top-floor wall caps

### Night mode

The moon button in the top bar darkens the frame of the screen (buttons, panels and menus) and the 3D background. Press it again to go back; the browser remembers the choice. The 2D paper stays white, the same as exported images (choose a dark paper under the 2D style's background if you like).

### Languages (Japanese, English, Korean, Traditional Chinese)

The language menu in the top bar (JP / EN / KR / 繁中) switches the language of the screen.

- Buttons, menus, the selection panel, notices, confirmation dialogs, and furniture and template names and descriptions all change to that language, and the browser remembers the choice.
- A link can add `?lang=en`, `?lang=ko` or `?lang=zh-Hant` to open in that language (it overrides the remembered language without changing it).
- Templates create their room names in the chosen language. Room names and text you wrote yourself stay as they are; switching languages never changes the plan data.
- Furniture and templates can be searched by their names in that language.
- Without a choice the app is in Japanese (it does not follow the browser language). In other languages the top bar shows no notice or alpha note (the note is in "About this app").
- The changelog is shown in English for languages other than Japanese.

### Plan-only edition (no 3D)

For editing just the 2D floor plan, open the plan-only edition at https://madori-5yu.pages.dev/plan/.

- It shows only the 2D editor: no 3D pane, view switch, 3D colors, heights, roofs, or 3D image export.
- It shares the saved plan with the full app, so "3Dでも見る" opens the same plan in 3D (in the same browser).
- It leaves the full app's view mode and 3D camera untouched.
- The full app shows a notice about the plan-only edition in the text area of the top bar (on screens at least 1600 px wide), where the alpha note was. Its × closes it and brings back the alpha note, which can also be closed; closed texts stay closed. The notice takes no extra height.

### 2D styles

"絵柄" above the 2D plan changes how the whole plan is drawn. The menu has two tabs, line art (線画) and background (背景), so the way lines are drawn and the ground (paper or board) can be combined freely (for example, pencil lines on a chalkboard or neon lines on parchment). Line-art samples are drawn on the current background, and background samples with the current line art. The plan data (shapes, sizes, colors) and the 3D view stay the same; only the drawing changes. Both choices are saved in the browser, and exported images use them too.

- 18 line-art styles, in five groups: line art, hand-drawn, Japanese and old, manga and games, and night and mood (listed below).
- 14 backgrounds: auto (follows the line art), white, washi, drawing paper, watercolor paper, parchment, copy paper, cream, blueprint blue, chalkboard, black, night, gloom, and game green. Paper textures and darkened edges change with the background, and brush-family line art blends floor patterns into the background color.

- 標準 (standard): the crisp line drawing as before.
- モノクロ (monochrome): the standard line drawing with every color turned into shades of gray, without paper texture; floor patterns stay in gray.
- ドット (dots): the whole plan drawn in square dots like a pixel-art map. Thin lines become one-dot lines on the dot grid (stair-stepped on curves, square at corners); thick lines such as walls and fills take one color per dot. Text stays sharp without blurring. Dots are 2, 3, or 5 px, and the plan moves one dot at a time so the dots do not flicker while scrolling.
- レトロゲーム (retro game): the dot style in the four greens of an old handheld game console. In-between shades mix the neighboring greens in a fixed dot pattern (dithering) that is attached to the plan, so it does not flicker while scrolling. The dot size can be chosen too.
- 筆・和風 (brush): drawn with a sumi ink brush on washi paper. Lines are pressed where the brush lands, end with a firm stop or a tapering sweep, change width with the brush pressure along the way, and wobble and bow slightly like hand-drawn lines; rectangles are drawn one side at a time and overshoot a little at the corners. Thick lines such as walls (and slightly thinner ones too) are drawn bristle by bristle and run dry toward their ends. Within a stroke the ink is darker where the brush lands and lighter where it runs dry, and it bleeds slightly into the paper. Fills are pale washes with slightly wavy, slightly darker edges and some mottling, white becomes the paper color, and the paper's fibers and mottling lie over everything. Text uses a brush-style typeface (kaisho or kyokasho, otherwise mincho) with a slight ink bleed. The same line always gets the same brush shape, so nothing flickers while moving or scrolling.
- 鉛筆 (pencil): a pencil sketch on white drawing paper. Each line is traced two or three times with small offsets, and ends overshoot or stop a little short. Thick lines such as walls are filled with fine strokes; fills are light colored pencil, with hatching that gets denser for darker colors (cross-hatching for the darkest). Text uses a handwriting-style kyokasho typeface.
- マンガ (manga): black and white. Lines are black; fills become screentone dots that follow how dark the color is, and very dark colors become solid black. The tone is fixed to the plan, so the dots do not move while scrolling.
- 設計図 (blueprint): pale lines on blueprint blue, with faint white fills and a drafting-style gothic typeface.
- 古地図 (old map): sepia pen on parchment. Colors fade into the paper, with mottling and darker edges over everything. Text is mincho.
- 黒板 (chalkboard): chalk on a green board. Lines are powdery with small gaps, fills are faint on the board, and text uses a handwriting-style typeface.
- ネオン (neon): glowing lines on a dark night background. Line colors become bright and vivid with a soft glow around them.
- CAD: thin lines on a black screen. Black lines become white, colored lines become CAD-like primaries by hue (red, yellow, green, cyan, blue, magenta), and fills use the background color to hide the lines below.
- コピー (photocopy): like a photocopied handout, in black and white with slightly stronger contrast, toner mottling, and specks. Floor patterns keep their texture without color.
- 水彩 (watercolor): thin lines and see-through paint. Colors are a little more vivid, paint pools slightly darker at the edges of fills, fills are mottled, and watercolor paper texture lies over everything.
- クレヨン (crayon): thick, slightly broken crayon lines and fills where the white paper tooth shows through, in vivid colors.
- 墨絵 (ink wash): sumi ink shades only, without color; only strong reds (such as blood) become vermilion. Floor patterns also lose their color.
- ポップ (pop): bold black lines and vivid colored halftone dots. Grays become black dots on white, and very dark colors become solid black.
- ホラー (horror): bone-white lines in the dark. Red things (such as blood) stay a deep, clear red, text has a red glow, and grime, stains, scratches, and heavy darkness at the edges lie over everything.
- In the brush family (brush, ink wash, old map, chalkboard, watercolor, and crayon), floor patterns (wood, tatami, tile, stone, grass) get a thin layer of the paper or board color so their colors do not stand out.
- Selection handles, lines being drawn, and the dashed roof outlines stay crisp in every style.

### Image export

"画像" in the top bar saves the plan as PNG images.

- Floors: the current floor, all floors in one image (each with its name), or one image per floor. Several floors share the same area and scale so they line up.
- Grid and room names can be left out. Dimensions and room areas follow the 2D view. Selection frames, roofs, ghost floors, and lock icons are never included.
- With a grid size chosen under 表示 and the grid included, the image edges snap to grid lines (the grid starts at the top-left corner) and 1マスの大きさ sets one cell to 50–140 px, to match the grid of online tabletop maps.
- 背景を透明にする leaves out the background color and paper texture (dot styles keep their background), and 画像をコピー copies the image to the clipboard.
- When the 2D style is not the standard one, the image is drawn in that style (dots of the same size as on screen; the paper or board, such as washi, blueprint blue, or the green chalkboard, is included).
- Line widths and text keep the same proportions as the whole plan shown in the 2D view, so large plans do not look faint when the image is scaled down. Resolution is at least twice the screen and 1.5 pixels per centimeter, reduced for very large plans so every device can create the image.
- "3Dの画像" saves the current 3D view at twice the screen resolution.

### Multiple editable roofs

- Add any number of gable, hip, flat, cone, dome, and regular polygon roofs
- Edit width, depth, and position for each roof
- Resize cone and dome roofs by diameter, or set width and depth independently for an elliptical footprint
- Regular polygon roofs support 3 to 12 sides, rotation and circumcircle diameter; corner resizing preserves regular sides
- Set cone, dome and polygon roof rise from 10 to 2000 cm, or leave it blank to calculate it from the footprint
- Assign each roof to a floor. Adding floors does not move existing roofs; hiding a floor also hides its roofs
- Raise or lower each roof with Raise/lower (cm), measured from the top of its floor's walls (negative to lower, up to ±3000 cm), so roofs on the same floor can sit at different heights
- Drag roofs on the 2D canvas
- Resize roofs from corner handles
- Swap width and depth with a 90-degree rotation
- Select roofs from either the 2D or 3D view. In 2D, click the dashed roof edge or a line inside the roof such as the ridge, or (with the Select tool) an empty spot under the roof such as the eaves; lines over gardens and ground floors work too, and where lines overlap, the roof of the floor being viewed is chosen
- Give each roof its own color with swatches (smoked tile, black, terracotta, vermilion, verdigris, blue and more) or a color code. Two extra digits for transparency make the roof see-through in 3D, and the 2D outline is tinted with the same color
- Roofs show no name on the 2D plan; their size appears only when dimension labels are on
- Lock, select, and delete roofs independently
- Automatically migrate legacy single-roof plans

If a room is selected before adding a roof, the new roof is sized around that room. Additional roofs created without a selected room are placed beside the previous roof so they do not disappear underneath it.

Round and polygon roofs can also be placed around a selected circle, ellipse or polygon wall. Polygon roofs inherit the wall's side count and orientation. The wizard tower and castle tower templates now use cone roofs; existing saved plans are unchanged.

## Persistence and File Transfer

### Automatic browser storage

Plans are saved automatically to browser `localStorage`. There is no login or cloud save.

If some saved items are invalid, the original data is backed up before valid items are recovered. Use the recovery banner to download the original JSON unchanged. If the backup fails, for example because storage is full, autosave stops to protect the original; export ongoing work with the regular Export button. Malformed JSON cannot be recovered automatically, but remains downloadable. New asks for confirmation before removing existing items, and can be undone.

- Main storage key: `madori-quick-3d-plan`
- View mode, the 2D/3D boundary position, dimensions, shadows, lighting, lower-floor display, and the 2D style with its dot size are also saved
- Reloading or reopening the app restores where you were looking in 2D (position and zoom), the 3D camera position and direction, floors and roofs hidden in 3D, the 2D roof display, the collapsed tool panel, which palette groups are open, and the design picked for each furniture type (switching the view mode, or loading a template, a new plan, or a file, still frames the whole plan)
- Data normally survives reloads and browser restarts
- Clearing site storage deletes the saved plan
- Data does not synchronize between browsers, computers, or domains

### JSON export and import

Export creates a file named `madori-YYYY-MM-DD.json`. It contains floors, rooms, walls, openings, furniture, shapes, roofs, colors, positions, lock states, and marker numbers (`markerLabel`).

Import restores a previously exported file. The loader also migrates older single-floor and single-roof formats where possible.

Combine adds exported files to the current plan; you can pick several at once. Choose how to place them (the choice is remembered): side by side (to the right of the current plan, roofs included, with a 200 cm gap and the top edges aligned; several files line up in turn), in the same place (at the positions saved in the file), or stacked (the file's floors go on top of the current top floor). Side by side and same place match floors by level (1F to 1F, basements to basements) and add missing floors. Roofs move with their floors, and added items get new ids. Afterwards, the added items on the shown floor stay selected, so you can drag them or use the arrow keys to adjust their position. One Undo removes everything that was added, including new floors. Combining into an empty plan keeps the file's positions and floors.

> [!TIP]
> Export important work regularly instead of relying only on browser storage.

## Privacy

- Floor-plan data stays in the current browser
- Plans are not uploaded to an application server
- No account, application database, or cloud synchronization
- No advertising
- Cookie-free Cloudflare Web Analytics is used for aggregate visit counts
- The feedback form is a Google Form: what you write and the filled-in environment (app version, browser, screen size, URL) go to Google; plan data is never sent. The form with images records the sender's Google account name, email address and photo

Imported JSON files are processed entirely in the browser.

## Data Model

The exported JSON has the following high-level shape:

```json
{
  "floors": [
    {
      "id": "floor-...",
      "name": "1F",
      "entities": [
        {
          "id": "room-...",
          "type": "room",
          "name": "Living Room",
          "x": 0,
          "y": 0,
          "w": 600,
          "h": 400,
          "color": "#ffffff"
        }
      ]
    }
  ],
  "activeFloor": 0,
  "selectedId": null,
  "roofs": [
    {
      "id": "roof-...",
      "type": "roof",
      "kind": "gable",
      "x": -40,
      "y": -40,
      "w": 680,
      "h": 480
    }
  ]
}
```

Coordinates and dimensions use centimeters. Common entity types are `room`, `wall`, `door`, `window`, `furniture`, `shape`, and `text`. A furniture item's `symbol` is its design number (shared by the 2D symbol and the 3D model) and `height` is the height of adjustable items; both are omitted at their defaults. Roofs are stored in the plan-level `roofs` array, with each roof's `floorId` identifying its supporting floor `color` its color (omitted for the standard color) and `elevation` its height offset in cm (omitted when 0). Legacy roofs without this field are assigned to the highest floor at load time. Deleting a floor also deletes its roofs; Undo restores both.

## Troubleshooting

### PowerShell refuses to run `npm`

Use the `.cmd` wrappers:

```powershell
npm.cmd install
npm.cmd run dev
```

### The browser shows `ERR_CONNECTION_REFUSED`

The development server is not running. Run `npm.cmd run dev` in the repository directory, keep the terminal open, and then visit `http://127.0.0.1:5173/`.

### The 3D view is blank

- Update the browser
- Try a current version of Chrome or Edge
- Enable hardware acceleration
- Confirm that WebGL is enabled
- Temporarily disable browser extensions
- Reload the page

### A saved plan disappeared

Clearing site data, closing a private browsing session, or changing domains removes access to that domain's `localStorage`. Restore from an exported JSON file if available.

### Cloudflare and GitHub Pages show different saved plans

Browser storage is isolated by domain. Data on `madori-5yu.pages.dev` does not automatically appear on `tghcgu.github.io`. Export the plan from one site and import it into the other.

### A deployment does not show the latest change

- Confirm the change was pushed to `main` or `develop`
- Check GitHub Actions or Cloudflare Pages build status
- Wait for the deployment to finish and hard-refresh the page
- Confirm the build output directory is `dist`

## Current Limitations

- This is alpha software, so the UI and file format may change without notice.
- Editing is designed for desktop PCs, but phones work too. At 760 px wide or less, the app fits the screen and opens straight to the plan; the tool and furniture list is a drawer opened with ≡ at the top left (choosing with a finger closes it), export and the rest are under “…” in the top bar, and the selected item's settings rise from the bottom. Opening the app on a phone or tablet shows a short how-to notice at the top (also when the browser requests the desktop site). Closing it hides it only until the next visit.
- It is not a replacement for architectural CAD, structural analysis, code review, or construction drawings.
- Dimensions, wall thicknesses, openings, furniture, and roofs are simplified representations.
- There is no account, cloud save, collaboration, or share-by-URL feature.
- 3D performance and appearance vary by browser and GPU.
- Very large plans or plans with many objects may become slower.
- Automatic saves are isolated by domain and browser profile.
